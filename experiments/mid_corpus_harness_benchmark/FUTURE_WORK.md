# Future work

The public package intentionally stops at aggregate evidence. The bounded next questions are:

- Run a larger, rights-cleared sample than five chapters.
- Add human bilingual judges and preregister the rubric.
- Add semantic QA for errors deterministic surface checks cannot see.
- Ablate ambiguity approval and glossary behavior separately.
- Run a live provider-native action trajectory only with permission to retain its non-copyright evidence.
