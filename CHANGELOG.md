# Changelog

## November 2026

- Story memory sends only names to each passage by default. Facts are still
  stored, and earlier runs replay with the settings they recorded.
- A run can continue an earlier run's memory, or read earlier chapters into
  memory before translating.
- Term alignment enforces only the translator's names.
- Fixes for saving memory, stopping runs, recording repairs and the workbench.
- The repository now covers the folder demo, the local workbench and the book
  runner. Older command-line tools are no longer included.
- Results from two new memory tests, in the README and the results page.
- November 10: a corrected count of name changes, which no longer treats a
  plural or a longer phrase as a change of name, tested on names no earlier
  test had read. Results are in the README and the results page.

## October 2026

- A local workbench for starting, watching and replaying runs.
- The folder demo, with a four-way comparison and recorded replay.
- Anonymous evidence for the September result, with a no-key verifier.

## September 2026

- Source-checked story memory, guarded repair, and recorded calls with replay.
- The first registered test on unseen chapters.

## July–August 2026

- The first public version of the harness.
